# 学习成长、习惯追踪与生活收藏

V1 第五阶段，2026-10-29。保留原站点、私有 D1、ChatGPT 身份隔离。无 AI、无 API Key、无自动演示数据。

## 学习成长

LearningGoal 增加可选 deadline、stages 与 resources。阶段具有稳定 UUID、标题、目标分钟数和可选期限；合计不能超过总目标，期限不能晚于目标期限。已有学习记录引用的阶段不能直接移除；先调整记录的阶段归属。学习目标状态由用户明确设置，不因达到预估分钟数自动代替用户判断学习完成。

StudySession 保存实际整数分钟、日期、笔记、可选目标及阶段、资料链接。每条独立 ID 仅汇总一次，阶段用于分组，不生成第二份时长。总进度 = 该目标实际记录分钟数 / 总目标分钟数，展示封顶 100%，实际分钟不截断。独立学习记录计入累计和月份时长，不计入任何目标。阶段进度仅使用归属该阶段的记录。

单条和每日全部学习记录合计均不超过 1440 分钟；常规写入拒绝未来学习日期。不同日期可分别补录。编辑替换原 ID 的分钟数，删除后重新计算。关联与阶段必须属于同一账户的现存目标。删除已有记录的目标会提示先解除关联，避免历史学习时长丢失。

目标和记录各可添加最多 30 个手动资料链接，笔记最多 2000 字。外链不自动请求或抓取内容。学习历史支持目标、日期、标题/笔记/资料搜索；每页 20 条，顶部累计与本月摘要不受历史筛选影响。

## 习惯计划、日历与统计

Habit 保存 frequency、weeklyTarget、weekdays、startedOn、timeZone、archived、scheduleHistory。每天目标指每个计划日一次；每周目标指一周完成若干个不同日期，不能高于计划日数量。未选择的星期为固定休息日；也可将某一具体日期记为休息日。

每个习惯使用自己的 IANA 时区解释今天，已有打卡后开始日期和时区锁定。允许补记开始日至今天，拒绝未来或开始日前日期。不同习惯的时区可以不同，首页打卡也使用习惯自身时区。

已有打卡后的频率、目标和星期调整，从下一个周一生效；同周再次修改替换尚未生效的那一条计划，已经生效的规则保留。当前周期按原规则计算，界面提示新规则生效日期。没有打卡时可直接调整开始日期和计划。

HabitCheckIn 每习惯、日期保留一个稳定 ID，当前状态 done / rest / void。首次记录以及每次状态/备注变化由服务器追加 history，包含时间、状态与备注。撤销（含 DELETE API）改为 void，不物理删除、不清空历史。重新完成同一日期使用原记录，防止重复计算。日期和所属习惯不能编辑迁移，需撤销原记录再补记正确日期。一天超过 5000 次变更时拒绝继续修改，已有历史不裁剪。

- 连续天数：连续完成的计划日数量；固定/临时休息日不增加也不中断。未完成的今天在当天结束前不使昨天的连续记录失效。每周习惯仍显示连续计划日，而非连续达标周数。
- 周完成率：自然周（周一至周日）内已完成天数 / 整周目标；当前周仅计截至今天的完成记录。每天目标的分母为开始日期之后的计划日，排除具体休息日；非计划日额外打卡计为执行日。每周目标为 weeklyTarget 与可执行天数的较小值。
- 月完成率：按自然月整月计划计算；每周目标在月初/月末跨月周按该月可执行日占整周可执行日的比例折算。界面显示一位小数的折算目标，百分比一位小数并封顶 100%。未来月份显示暂无计划统计；开始日期之前不计分母。

打卡 history 不产生额外完成次数。休息和撤销不计已完成天数。日历区分完成、休息、撤销、未记录与未来禁用日，点击日期可补记、修改备注和查看完整变更历史。

有打卡历史的习惯禁止硬删除，使用归档隐藏，归档后仍可查看与修正已有日期、恢复习惯；不能为归档习惯新增日期记录。备份包含完整 history 和 scheduleHistory。恢复事务会拒绝缺少现有打卡/变更历史、改变历史规则或开始日期/时区的备份；请使用包含完整历史的最新备份。

## 收藏与外链

Bookmark 增加自定义 category 和数组 tags；旧逗号分隔标签兼容读取并去重。标题、URL、分类、标签和个人笔记参与搜索，支持分类与标签组合筛选。保留创建/更新时间与版本校验，编辑或删除后首页最近收藏更新。

为兼容原有 200 字符标签文本，单标签最多 200 字符，最多 100 个标签；读取、编辑和导出均不截断旧长标签。输入过长时明确拒绝。

只允许 http/https 且不带用户名/密码的 URL，拒绝 javascript/data/ftp 等地址。用户文本 HTML 转义；外链新标签打开，带 noopener、noreferrer 和 no-referrer。没有外部缩略图、favicon 请求或网页抓取；不自动暴露收藏清单。

收藏导出在同源鉴权 POST 接口中重新读取当前账户数据，包含所有筛选结果而非仅当前页。CSV 包含标题、URL、分类、标签、笔记和时间，使用 UTF-8 BOM、CRLF、双引号转义、用户文本公式注入防护。JSON 包含完整记录与筛选说明，不含 owner_id。两种清单均不是完整恢复备份；恢复请用设置中的 LifeHub V2 备份。
