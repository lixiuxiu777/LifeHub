# LifeHub 设计规范

方向：安静、自然、克制的个人效率空间。暖白背景、鼠尾草绿主色、细边框卡片；首页以“生长”植物线稿呼应生活主题。插画、图标均为本地 SVG，无外部字体和图片请求。

| 类型 | 规范 |
|---|---|
| 主色 | 浅色 #356D55；深色 #A3C49E |
| 背景 / 卡片 | 浅色 #F6F7F5 / #FFFFFF；深色 #171E1B / #202A24 |
| 正文 | 浅色 #263C33；深色 #E0E9DF |
| 字体 | Inter 如本机已安装，回退 Segoe UI / 苹方 / 微软雅黑 / sans-serif；不联网下载 |
| 页面标题 | 桌面 30px；手机 26px |
| 卡片标题 | 桌面 14px；手机 13px |
| 业务说明 | 11–13px；装饰英文与元信息另用小字号 |
| 圆角 | 卡片 16px、按钮 8px、弹窗 20px |
| 布局 | 内容最大 1520px；桌面左侧栏 230px；卡片间距 19px |
| 断点 | ≥1600 三列；默认两列；≤540 单列；≤800 抽屉导航 |
| 功能色 | 待办/习惯绿、日程蓝、消费橙、学习紫、收藏玫瑰色 |

首页层级：页面标题与日期 → 生活寄语与快速入口 → 四项汇总占位 → 可配置卡片 → 数据状态说明。占位不显示为真实统计，不默认插入示例。

交互：卡片配置在服务器保存成功后生效；上下按钮支持键盘与触屏；空卡片提供真实新增入口。六类快速新增使用统一表单；模块页支持编辑与删除确认。记录与配置保存在 D1，界面明确区分本机开发库与私有云端。完整备份恢复须经预览和确认。

状态：无记录时显示真实空状态和零统计；真实加载失败时不显示假零值，保留错误与重试入口。当前不提供虚构演示数据。所有卡片隐藏后有可恢复入口。默认视图支持总览、紧凑、专注今日；日期、时间格式和时区统一应用。

可访问性：语义 main/nav/article/heading；SVG 装饰图标 aria-hidden；图标按钮有标签；键盘 focus-visible；原生 dialog 锁定背景焦点，Escape 关闭；手机隐藏导航使用 inert，打开后循环侧栏焦点；跳转正文链接不破坏哈希路由；支持 prefers-reduced-motion。
